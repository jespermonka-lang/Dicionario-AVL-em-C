# Dicionário Português-Português utilizando Árvores AVL

## Sobre o projeto

O projeto consiste na implementação de um dicionário Português-Português em linguagem C, utilizando uma árvore AVL para armazenar e organizar palavras e seus respectivos significados.

O objetivo é aplicar conceitos de estruturas de dados, algoritmos de busca e balanceamento de árvores binárias, visando à eficiência das operações.

## Funcionalidades

- Criação de uma árvore AVL.
- Inserção de palavras e seus significados.
- Remoção de palavras.
- Busca de palavras e consulta de significados.
- Impressão das palavras em ordem alfabética.
- Prevenção de inserções duplicadas.
- Balanceamento automático da árvore.
- Implementação das quatro rotações AVL (LL, RR, LR e RL).
- Liberação da memória ao finalizar o programa.

## Conceitos abordados

- Algoritmos e estruturas de dados.
- Árvores binárias de busca.
- Árvores AVL.
- Recursividade.
- Ponteiros e alocação dinâmica de memória.
- Manipulação de strings.
- Complexidade de algoritmos.
